laya-bangla · বাংলা সিদ্ধান্ত মডেল

Write a message in Bangla, Banglish (Bangla in English letters), or a mix. The model answers fixed questions about it (which team should handle it, is it hate speech, how serious is it) and shows how sure it is about every option.

Everything runs in your browser. Your text never leaves this page. The first visit downloads the model once (about 640 MB); after that it loads from your browser's cache.

Use the model

Python

pip install "laya==0.4.11"

import laya
agent = laya.load("algolyzer/laya-bangla", revision="v2")
questions = {
    "sector": {
        "type": "choice",
        "instructions": "নাগরিকের এই সমস্যাটি কোন সেবা খাতের?",
        "criteria": {"water": "পানি সরবরাহ", "electricity": "বিদ্যুৎ", "waste": "ময়লা ও পরিচ্ছন্নতা"},
    },
}
print(agent.predict("আমাদের এলাকায় তিন দিন ধরে পানি নেই", questions)["answers"])

JavaScript (browser or Node)

This page uses laya-ts, Laya's TypeScript runtime, with the ONNX files in the model repository:

import { Agent } from "./vendor/laya-ts/index.js";
const agent = await Agent.load("algolyzer/laya-bangla", { subfolder: "onnx/int8", revision: "7c8ad162a66c05409f9278e047e3ee80c24017a8" });
const result = await agent.predict("আমাদের এলাকায় তিন দিন ধরে পানি নেই", questions);

The three question types

TypeThe model returnsExample
choicethe best option, plus a probability for every optionWhich department should handle this?
noulthe probability that the answer is yesIs this comment hate speech?
scorea level on an ordered scale, with a probability per levelHow urgent is it: low, medium, high?

Write instructions and options in Bangla or English. noul questions use exactly the options "false" and "true"; score options are a list from lowest to highest.

Known limits

  • New kinds of yes/no questions can get worse. All trained yes/no tasks are about moderation, so the model says "no" readily. Test new yes/no questions first.
  • Rare cases are missed. Only about 8% of BanTH comments are abusive; the model finds few of them.
  • Complaint severity is weak (about 40–43% over three levels).
  • Voice-assistant routing was trained on Bangla script only. Banglish commands are often misrouted.
  • No real customer-support data was available; the support preset is a diagnostic.
